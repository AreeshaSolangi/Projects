# 📊 Bank Loan Financial Model & Dashboard (Excel)

## 📌 Project Overview
This project focuses on building a **Bank Loan Financial Model and Interactive Dashboard** in Excel to analyze loan performance and key financial metrics.

Starting from raw loan data, a complete financial model was developed along with a dynamic dashboard to provide actionable insights into business performance.

---

## 🎯 Objectives
- Analyze loan portfolio performance
- Track key financial KPIs
- Identify good vs bad loans
- Monitor trends using time-based comparisons (MTD & MoM)

---

## 📊 Key Features

### 🔹 KPIs Tracked
- Total Loan Applications  
- Total Funded Amount  
- Total Amount Received  
- Average Interest Rate  
- Average Debt-to-Income Ratio (DTI)  

### 🔹 Loan Analysis
- Good Loans vs Bad Loans classification  
- Breakdown by:
  - State  
  - Loan Purpose  
  - Loan Term  
  - Employment Length  
  - Home Ownership  

### 🔹 Time-Based Analysis
- Month-to-Date (MTD) tracking  
- Month-over-Month (MoM) comparison  
- Trend analysis for performance monitoring  

---

## 🛠 Tools & Techniques Used
- Microsoft Excel  
- Pivot Tables  
- Data Cleaning & Transformation  
- Financial Modeling  
- Dashboard Design
